# Reconnect flow

A token refresh must never drop the socket. We keep the room open,
swap the token and resume from the last acked `seq`.

<Callout kind="decision">
  Refresh happens on the open connection; reconnect is the fallback.
</Callout>

## Sequence

1. The client sees `unauthenticated` with reason `token`.
2. It refreshes and re-sends `hello` on the same socket.
3. The hub replays from `since_seq` ([[Sync protocol#Frames]]).
